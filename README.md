# HONG XL Portfolio Template

---

## 🇯🇵 日本語

シンプルで分かりやすい情報紹介用のWebテンプレートです。  
日本語・英語・中国語の多言語に対応しており、個人利用・商用利用の両方に適しています。

---

### ✨ 特徴

- 多言語切り替え対応（JP / EN / ZH）
- JSONによるコンテンツ管理で編集が簡単
- レスポンシブデザイン（PC / SP対応）
- 純粋な HTML / CSS / JavaScript（フレームワーク不要）
- 画像の差し替えが可能、拡張しやすい構造

---

### 📁 プロジェクト構成
site/
├─ assets/
│  ├─ css/        # スタイルシート
│  ├─ fonts/      # フォントファイル
│  ├─ i18n/       # 多言語・テキスト設定
│  ├─ images/     # 画像リソース
│  └─ js/         # JavaScriptファイル
├─ index.html     # トップページ
├─ projects.html  # プロジェクト一覧ページ
├─ LICENSE.txt    # ライセンス
└─ README.md      # 説明ドキュメント

---

### 🚀 使用方法

#### 1. ローカルでのプレビュー

ローカルサーバーを使用してください（推奨）：

- VS Code + Live Server

⚠️ `file://` で直接開くと正常に動作しない場合があります

---

#### 2. テキストの編集

以下のファイルを編集してください：
site/assets/i18n/*.json 

---

#### 3. 画像の差し替え

以下のフォルダ内の画像を差し替えてください：
site/assets/images/

- banners：トップページのメイン画像  
- projects：プロジェクトカードの画像  

---

### ⚠️ 注意事項

- 本テンプレートは JavaScript により JSON を読み込みます
- 必ずローカルサーバー環境で動作させてください
- 画像サイズが大きいと表示速度に影響します
- WebP形式の使用を推奨します
